## About

Mobilixir Technologies is an independent software consultancy focused on building high-quality mobile and web products. Our team brings over a decade of hands-on experience delivering production mobile applications, including mobile banking platforms for major financial institutions, where reliability, security, and performance are non-negotiable.

We work with startups, product teams, and enterprises that need senior engineering depth without the overhead of a large agency.

## What We Do

| Capability | What it covers |
| --- | --- |
| **Cross-platform mobile** | React Native apps on the New Architecture (Fabric, TurboModules), custom native modules, performance profiling, and release engineering |
| **Native iOS** | Swift and SwiftUI, modern concurrency (async/await), AVFoundation, Keychain and secure storage, App Store delivery |
| **Backend and real-time** | Elixir and Phoenix, LiveView, channels, fault-tolerant services built on the BEAM |

## How We Work

- **Senior-led delivery.** You work directly with experienced engineers, not a hand-off chain.
- **Production mindset.** Typed codebases (strict TypeScript, modern Swift, idiomatic Elixir), automated tests, CI/CD, and observability from the start.
- **Security-aware.** Experience building for regulated, high-trust domains such as banking and fintech.
- **Transparent communication.** Clear scoping, regular demos, and written technical decisions.

## Open Source

We contribute to the React Native ecosystem and publish the tools we wish existed. Libraries are built with full New Architecture support.

| Project | Description |
| --- | --- |
| `react-native-privacy-guard-kit` | Privacy protection utilities for React Native apps |
| `react-native-root-jail-detect` | Root and jailbreak detection |
| `react-native-qr-camera-pro` | High-performance QR and barcode scanning |
| `react-native-i18n-kit` | Zero-dependency localization with native Kotlin/Swift implementations and 16KB page-size compliance |
| `rn-upgrade-doctor` | CLI to help plan and execute React Native upgrades |

We also publish technical articles on [Dev.to](https://dev.to/rushikeshpandit) and the [Mobilixir blog](https://www.mobilixir.in/blog) covering React Native internals, native modules, and mobile engineering practices.
